# 公开快照范围与隐私处理

本次从明确的源码目录与文本扩展名白名单生成独立副本，创建全新仓库时不携带开发仓库历史。

包含：Python/JavaScript/CSS/HTML源文件、测试代码、合成SQL结构及新写项目说明。仅随代码保留供应商名称、通用成员别名、历史技术标识和示例URL。

不包含：真实项目目录、数据库及其sidecar、客户资料、任务卡、交付回执、原始聊天或运行日志、原工程文档、图片、安装产物、私钥、认证配置、用户HOME、第三方SDK/CLI、依赖缓存、现有Git历史和私有审核资料。

个人绝对路径使用demo占位，内部工程标记与实际任务/会话编号示例化。导出修改只作用于副本，没有改变开发端、真实Adapter配置或正在运行的服务。

`PUBLIC_MANIFEST.json`记录公开文件的相对路径、字节数和SHA，便于核对；它不包含本机来源位置。扫描不能数学证明不存在任何敏感信息，公开前仍需按具体文件范围审查。本文件不宣称功能测试通过。
